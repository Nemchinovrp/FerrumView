# FerrumView

Просмотр HLS-потоков камер в браузере.

## Запуск

Проверено с Rust 1.92.0 и установленными системными библиотеками FFmpeg.

```sh
cargo +1.92.0 run -- 'https://example.com/index.m3u8?token=...'
```

Откройте http://127.0.0.1:3000. Без аргумента открывается первая камера из списка; URL также можно ввести вручную.
Ссылку с `&` или `#` передавайте в кавычках. Фрагмент после `#` плеер удаляет.
URL из аргумента не сохраняется в файлах или браузерном хранилище.

Axum отдаёт страницу и начальный URL; браузер получает видео напрямую от камеры.
Safari использует встроенную поддержку HLS, остальные поддерживаемые браузеры —
hls.js с CDN jsDelivr (нужен интернет). Сервер камеры должен разрешать CORS
для плейлистов, сегментов и ключей. TLS-ошибки сервера камеры не обходятся.
Плеер показывает состояние, поддерживает переподключение, звук и полный экран.
Сервер слушает только локальный адрес. Остановка: Ctrl+C.

## Диагностика пакетов

Прежний режим FFmpeg сохранён:

```sh
cargo +1.92.0 run -- --inspect 'https://example.com/index.m3u8'
```

## Проверки

```sh
cargo +1.92.0 fmt -- --check
cargo +1.92.0 check --offline
```

## Список камер

Добавляйте камеры в `streams.txt` в рабочей директории запуска (корень проекта):

```text
Двор | https://example.com/yard/index.m3u8?token=...
Парковка | https://example.com/parking/index.m3u8
```

Пустые строки и комментарии, начинающиеся с `#`, пропускаются.
Если `streams.txt` отсутствует, читается `stream.txt`.
Список перечитывается при обновлении страницы — пересборка не нужна.
На странице один плеер: нажатие на название переключает камеру.
Запуск списка: `cargo +1.92.0 run --offline`.
